# КРУГ — мини-приложение (фронтенд)

Это фронтенд Telegram мини-приложения КРУГ: `index.html` (само приложение), `admin.html` (админка), `privacy.html`. Хостинг — GitHub Pages. Сервер — отдельный репозиторий **krug-backend** (Railway), адрес задан в `API_BASE` в html-файлах.

**Полный контекст проекта, правила работы и принятые решения — в `CLAUDE.md` репозитория krug-backend.** Если он не подключён к сессии, попроси владельца добавить его.

Коротко:
- Владелец не программист: объяснять просто и коротко, общение на русском, весь код пишет Claude.
- Главный приоритет — качество и безопасность.
- Дизайн: чёрно-белый минимализм, шрифты Unbounded (заголовки) и Manrope (текст).
- Всё в одном файле (HTML + CSS + JS), без сборщиков. После правок проверять, что JS внутри `<script>` без синтаксических ошибок.
- Приложение шлёт `x-telegram-init-data` во все запросы к API (функция `apiRequest`).
